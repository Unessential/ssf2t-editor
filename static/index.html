Jump:

Tiles are 16×16 CPS-2 OBJ tiles in a grayscale ramp (pen 15 = transparent).

Settings on this tab apply to the whole game: every character, both versions. Per-character settings are on the Character tab.

Health

Both players, every round (originally 144). The bar shows at most 144, so higher values keep it full until health drops below 144. Shared by every character.

Stun

Base stun points a normal attack adds on a standing or crouching hit, by strength; the game then adds a random amount per hit. The timer is how long (in frames) the stun meter waits before draining. Shared by every character.

Reaction 0x0C table (not yet identified)

A second base-stun table the game uses for hit reaction 0x0C. That reaction didn't show up on standing, crouching or sweep hits, so it's unclear which hits use it.

Dizzy

Stun points needed to get dizzied, by how many times that player was already dizzied this round. Shared by every character.

Damage table

Base damage of each damage class in a 2P match. Every attack box has a class (pick it in Hitbox editing on the Character tab); changing a class here changes every attack of that class, for all characters. The game adds a small random amount, then the defender's defense takes off its share.

Game speed

Frame skip for each GAME SPEED setting in the service menu. Lower runs faster: 64 gives about 1.44 game ticks per screen frame, 112 about 1.29, 128 about 1.26. 255 turns frame skipping off (exactly one tick per frame). On this ROM's region the menu's TURBO 0–3 most likely use entries 0–3, and FREE SELECT's three choices use entries 1–3 (0–2 on Japanese boards). Shared by every character.

Input leniency

Every special move of every character at once. Per-move versions are in Special move inputs on the Character tab. Times are game ticks (about 1.3 per frame at Turbo speed; 1 per frame with frame skip off).

Shortcuts: 2, 4, 6 and 8 in a motion (and a charge move's release) also accept the two diagonals next to them, like newer games.

–

Ticks allowed to reach each next direction (stock: random 8–15).

ticks

Adds (or with a negative number, takes) ticks from the time to press the button after the last direction (stock 12 / 10 / 8 for light / medium / heavy).

Turn on edit mode to change these.

Special move inputs

Motions in numpad notation, facing right: 2 down, 6 forward, 4 back, 8 up, 3 down-forward, 1 down-back (236 = quarter circle forward, 623 = dragon punch, 1632143 = pretzel). The game tries the moves top to bottom and the first match wins, so a motion that contains another move's motion needs to sit above it.

Patch

Edits are kept in memory until exported or patched. IPS / BPS are verified; if your edits span several ROM files you get a zip with one patch per file. MRA is unverified. Patch ROM now writes the edits straight into ssf2t.zip in the data folder (first-time backups go to *.orig).
